# 网站部署、账号与云同步

## 配置

| 环境变量 | 用途 |
| --- | --- |
| `DATABASE_URL` | 运行时 PostgreSQL 连接。Vercel 推荐连接池地址，并按服务商要求启用 TLS。 |
| `DATABASE_MIGRATION_URL` | 可选迁移直连地址，未设置时使用 `DATABASE_URL`。 |
| `POSTGRES_PASSWORD` | Linux 配套 PostgreSQL 密码；启动脚本生成十六进制随机值。手动填写须适用于 URI。 |
| `LUMEN_CREDENTIAL_KEY` | Base64 编码的 32 随机字节，用于 AES-256-GCM 加密音源 Cookie。不得加 `VITE_` 前缀。 |
| `LUMEN_SETUP_TOKEN` | 首次创建管理员的随机口令。初始化后接口关闭；不会反复覆盖管理员密码。 |
| `LUMEN_COOKIE_SECURE` | HTTPS 下启用安全会话 Cookie；Linux 默认为 true。可信局域网 HTTP 调试可设 false。Vercel 强制 true。 |
| `LUMEN_PLAYBACK_LIMIT` | 每个用户每分钟播放地址请求上限，默认 30；每次只允许一首歌曲。 |
| `LUMEN_LOGIN_LIMIT` | 登录每个客户端地址每分钟上限，默认 20；用户名另有每分钟 10 次限制。 |
| `LUMEN_REGISTRATION_LIMIT` | 注册、初始化、重置分别按客户端地址每分钟限制，默认 5。 |

音源密钥与数据库必须分别备份。密钥丢失后无法解密原凭据，需要使用新密钥重新扫码绑定；不要在仍使用旧密文时直接替换密钥。管理员密码哈希和会话独立于该密钥。

现有 Linux `LUMEN_AUTH_USER`/`LUMEN_AUTH_PASSWORD` 仍可作为全站额外访问密码，与 Lumen 网站账号不是同一层。Linux 限流使用直连客户端地址；位于反向代理后时，匿名注册/登录可能共享代理地址额度，可按部署规模调整。Vercel 使用平台提供的客户端地址头。不要将未信任的代理地址头直接当作身份。

## 首次部署与升级

1. 配置专属数据库、音源加密密钥和随机初始化口令。
2. 显式运行 `npm run db:migrate`。SQL 迁移有已执行记录与事务锁；请求路径及前端构建不执行迁移。Linux Compose 的 `migrate` 服务承担这个步骤。
3. 构建并启动网站。根项目使用 `npm run build` / `npm start`；Vercel 使用独立工作区的 `npm run build:vercel`。
4. 通过 HTTPS 打开 `/admin`，输入初始化口令，创建管理员。用户名为 3–32 位小写字母、数字或下划线，密码为 12–128 个字符。
5. 在“音源账号”中扫码并在手机确认。成功绑定后才启用在线播放。
6. 在“用户与邀请码”生成邀请码，自行交给受邀用户。邀请码仅显示一次、只能使用一次、7 天后失效；无需邮件服务。

升级时先备份数据库，再运行迁移、发布应用。迁移脚本打包在 `server/migrations` 中。Vercel 预览部署不应连接生产数据库；构建任务不需要数据库凭据。Linux `stop` 和 `update` 均不删除数据库卷。禁止用 `docker compose down --volumes` 操作生产数据。

若网站提示“账号与同步服务暂时不可用”，检查数据库连接、迁移版本与连接权限。若提示“音源加密配置不可用”，检查原加密密钥。数据库未配置或故障时，不会匿名回退播放。

## 管理与恢复

- “音源账号”支持扫码绑定、更换、检查、停用和移除。新账号验证成功前保留旧账号；旧二维码不能覆盖后来的绑定。
- 普通用户的网易云登录、歌单读取和退出操作只使用个人凭据。默认音源凭据不发到任何浏览器。
- “用户与邀请码”支持禁用/恢复用户、撤销邀请码、创建一次性密码重置凭据。重置凭据 1 小时有效，创建时注销用户已有会话；使用后立即失效。
- 用户可在网站账号面板修改密码；修改后所有会话失效，需要重新登录。
- 最后一个管理员不能被禁用。若唯一管理员忘记密码，由数据库拥有者使用受控维护脚本重置：在服务器通过标准输入提供新密码，复用 `server/security.cjs` 的 `passwordHash`，更新目标管理员的 `password_hash` 并删除其 `lumen_sessions`。不要重新开放公开初始化接口，也不要将明文密码写进命令行或日志。
- 服务状态提供数据库可用性、账号检查时间及近 24 小时音源失败数。只保存分类，不保存原始上游错误、Cookie 或播放地址；失败分类保留 7 天。

## 同步规则

- 服务器按账号隔离数据。歌单与条目分别使用稳定标识；同一首音乐的不同列表条目可以独立删除。本地文件引用独立于列表条目。
- 同步请求提交操作列表和已接收游标。操作有唯一 ID，重试不会重复累计；服务器按账号串行合并并分配游标。首次连接返回快照，之后增量返回，每次最多 500 项。
- 常见新增、删除自动合并；名称以服务器后收到的修改为准；删除标记永久保留，离线旧修改不能复活歌单/条目。重新添加使用新条目标识。
- 前台启动、重新联网、切回页面及每 30 秒拉取；本地修改保存后批量推送。失败保留待提交队列，可在账号面板手动重试。
- 收听时长每 15 秒分段，暂停、切歌、页面离开时补交；未提交片段保存在本机。清空统计会创建新的统计代次，迟到的旧记录不恢复已清空统计。
- 本地音频、嵌入封面、Blob URL、设备目录路径与个人网易云 Cookie 不上传。无本地文件的歌曲显示状态，自动播放跳过，全部不可播放时停止；手动选择文件可关联原条目。
- 主题、语言、播放进度、当前选择、音量和均衡器是设备设置，不跨设备控制播放。
- 首次登录发现访客数据时，明确询问是否导入；原始访客数据保留。导入有账号/设备迁移标识并对统计分块去重。不同账号使用不同缓存及文件命名空间；切换账号立即停止旧播放器。
- 删除同步内容会在相应设备下次同步时清理已无引用的本地缓存文件。清除浏览器数据会丢失该设备本地音频；云端只能恢复名称和在线歌曲信息。

## 验证与运行边界

Vercel 已配置 `"regions": ["sin1"]`，将 Node.js 函数固定在新加坡，配合部署者后续连接的新加坡数据库；Hobby 也支持单一区域。变更区域须重新部署。此设置不改变全球 CDN 分发，也不会迁移数据库，数据库应单独选择与函数接近的区域。官方说明：https://vercel.com/docs/functions/configuring-functions/region 、https://vercel.com/docs/regions#region-list 。

`test:managed` 使用 PostgreSQL WASM 引擎运行真实 SQL 与事务测试；`test:cloud` 用两个独立客户端缓存验证离线合并；`test:site` 在真实浏览器操作构建页面。它们不等同于生产网络、真实 PostgreSQL 连接池或 Linux 数据卷验收。

`test:linux` 放在 CI 或可用的 Linux Docker 环境运行，创建独立随机测试项目并检查数据库/应用重启后的管理员会话和歌单恢复。不要在当前不可用的本地 Docker 环境运行。

真实公共音源最终验收须在已部署的 `/admin` 中扫码并确认，再由邀请用户登录测试有权限的歌曲。QR 图片生成、等待状态及模拟凭据测试不能替代此验收。在线播放仍受上游账号、歌曲权限和网络限制；公共音源失效不会回退个人或匿名账号。
